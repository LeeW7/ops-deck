Proposed Fixes
  • 1
    Add Timestamp Validation
    Prevent older HTTP poll data from overwriting newer WebSocket updates by comparing timestamps
  • 2
    Improve Job ID Matching
    Ensure job updates use the same ID format for matching (issueId field)
  • 3
    Add Manual Refresh
    Allow users to force refresh to recover from stuck states
  • 4
    Debug Logging
    Add detailed logging to diagnose future status sync issues
